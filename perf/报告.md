# 真实界面与官网设计改造：性能结论

本轮优先满足用户明确要求的真实桌面UI还原和官网重构。功能与还原检查通过不代表性能目标通过：**打开到实际输入 p75 从1100.7ms变为1314.0ms，慢19.4%；「降一半」探索目标没有达成。** 不宣称全站提速。

## 最终配对实验

原始数据：`bench/paired.json`。2026-11-16 20:20:42–20:21:24（Asia/Shanghai），旧版固定提交750bbe8与最终新版构建以A、B顺序交替各10次，同一机器、相同静态HTTP服务、Fast4G20ms/4Mbps/3Mbps、CPU不限速、1440×900、DPR1、每次新冷缓存会话。测试期间所有其他浏览器验证已退出。新版构建标识为 `index-DEI4zSke.js` / `index-DGRntA8w.css`。没有把不同时间段的过程数字用于最终降幅。Electron offscreen60fps避免隐藏窗口降频。

真实背景按需只在进入VIBE加载，**没有**在首页先预取假装切换快。截止输入回显的Resource Timing中没有森林图。完整演示加载花费额外流量是本次真实还原的必要成本，列入新版预算，不能删图伪装零成本。

修复了第一次构建中残留的大PNG引用；删去生成CSS中演示不使用的源规则，保留真实所需样式；没有增加独立JS动效框架。以上是可核实的字节变化。由于两版功能与页面设计同时变化，且过程测量时机器负载不同，**不为每项编造节省毫秒的贡献**。字节减少没有在两次独立同功能实验中稳定证明导航更快，因此只视为资源预算指标，不把它宣称为已证实的体感代理。

## 护栏结果

最终20/20轮实际键盘输入成功，草稿在工作台/VIBE/撤回切换后保留；模式更新跨过绘制帧后才结束；产品区真实可见图片加载完成后才结束；1440×900视口一致；无横向溢出、无裸翻译key。官网其他移动端、中英、减少动态效果、真实Release下载回退、弹窗键盘和桌面截图对照由对应功能台架独立验证。

开工前固定旧版预算 `bench/ceilings.json` **保留原值**。固定上限与最终配对A的比较均未通过导航、总字节、请求和首次VIBE项。最终配对返回工作台与撤回项通过。没有移动旧上限、丢弃失败样本或把假界面更快说成真实性能改进。

`bench/ceilings-fidelity-v1.json` 明确标记为**本次真实UI的新功能预算**，以最终新版建立后续回归上限；它通过仅说明未来改动不得继续退化，不代表赢过旧版。运行方法见 `bench/README.md`。

## 发布与限制

用户已授权完成检查后直接提交推送，本轮交付Git源码，不修改DNS/CDN/托管平台配置。没有可核实的生产域名，也没有CrUX真实用户p75；未完成线上前后测速，不能宣称生产部署或线上提速。

回滚使用 `git revert <本次提交>`，禁止force push。建议后续以保持同一真实UI功能为前提，单独优化主线程挂载成本、按需代码/样式边界，并进行同功能成对实验；不为了挤旧版假界面预算删去用户明确要求的真实控件或图片。
