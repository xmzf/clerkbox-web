确定性计数（演示首轮输入及三场景操作后）：4个本地请求，响应体381,602字节；其中 JS266,573、CSS48,355、图片64,438、HTML2,236字节。HTTP 服务不压缩，报告的是响应体字节，不能与 Vite 展示的 gzip 数字混用。Release API 不纳入关键路径计数。

首屏路径是 HTML → CSS/JS → React 挂载 →可输入。最长本地依赖为主 JS；旧版主 JS 的解析和挂载形成约308ms的 p75 长任务累计。完整 Resource Timing 排序在原始 JSON 每轮 `resources` 中。

基线棘轮在业务修改前固定：导航到输入 p75 上限1098.5ms（5%系统噪音），资源体积381,602字节和本地请求4个无额外容差。帧级切换允许一帧16.7ms量化噪音。新增真实 UI 导致的必要成本须明确报告，不能悄悄移动上限。
